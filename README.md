## 它是什么

一个**为十英尺观看距离设计**的短剧客户端。遥控器五向键加确认键即可完成全部操作，不需要触摸、不需要鼠标。

界面采用**影院极简风加沉浸式封面取色**：曜石深空底 `#090a0f` 配纯白胶囊按钮与焦点环，首页 Hero 左文右完整 2:3 竖版海报，顶部导航常驻、不随内容滚动消失。

- **Hero 续播态**：主按钮直接显示「继续观看 · 第 N 集」，下方带观看进度条。
- **封面动态取色**：采样当前 Hero、焦点卡片或详情页封面的主色调，驱动底层径向氛围光平滑过渡。
- **搜索页**：QWERTY 三行十键、热词取真实热播榜、本地历史；输入拼音首字母命中片名，精确匹配置顶。
- **详情页相关推荐**：按作品关联拉取，选集区下方续接一行，遥控器按「下」直达。
- **播放页黑边填充**：竖屏短剧在 16:9 屏幕上用同帧封面模糊填充，不留纯黑边。
- **老设备兼容**：产物禁用 `aspect-ratio`、`@layer`、`color-mix`、`:has()`、`@container`、`oklch()`，`clamp()` 全部补普通值兜底，`mask-image` 带 `-webkit-` 前缀。

## 项目来源

本项目是 [zxsos/HGhubX](https://github.com/zxsos/HGhubX) 的 **Android TV 定制分支**，非上游官方项目，与上游维护者无隶属或合作关系。基线取自其 `upstream-tv` 分支，在它的基础上做了这些改动：

- **品牌**：HGhubX → HGhubTV，包名 `com.hghubtv.app`
- **界面**：重构为影院极简风；首页 Hero 左文右 2:3 海报构图并接入封面取色氛围光；搜索页重做为 QWERTY 键盘 + 真实热播榜热词 + 本地历史；详情页新增相关推荐
- **兼容**：产物按 Chrome 66 收紧，构建链末端加产物闸门脚本 `scripts/check-legacy-css.mjs`
- **图标**：全套重绘为黄橙渐变圆角方块 + 黑色播放三角
- **构建**：CI 拆出 TV 专用流程，签名固定带 v1（TCL 部分机型只认 JAR 签名）

接口调用、播放、收藏、集数管理等业务逻辑沿用上游实现，未做改动；本项目不新增任何内容来源、不提供下载功能。

## 下载安装

最新版见 [Releases](https://github.com/feyakit/HGhubTV/releases)。

| 包 | 适用 |
|---|---|
| `HGhubTV_<版本>_arm.apk` | 32 位：老投影仪、部分电视盒子 |
| `HGhubTV_<版本>_arm64.apk` | 64 位：主流电视、盒子 |
| `HGhubTV_<版本>_x86_64.apk` | 模拟器、云机 |

安装要点：

- 包名 `com.hghubtv.app`，leanback 启动器入口。智能电视上可能出现在「应用」里而不是主屏第一排。
- 签名带 **v1（JAR）**，因为 TCL 部分机型的安装校验只认 v1，缺了会 `INSTALL_FAILED_VERIFICATION_FAILURE`。
- 投影仪与老电视优先装 `arm`；新设备（Google TV 等）装 `arm64`。

## 遥控器操作

| 场景 | 按键 |
|---|---|
| 顶部导航 | ↑ 进入导航，←→ 切换页面，↓ 回到内容区 |
| 首页货架 | ←→ 移动卡片（实时联动背景取色），↑↓ 换行或回 Hero |
| 浏览页分类 | ←→ 切换分类胶囊，↓ 进入海报墙 |
| 搜索 | 确认打开键盘，方向键选字，返回收起 |
| 详情页 | 默认焦点在「播放」，↓ 进选集，再 ↓ 进相关推荐 |
| 播放页 | 确认唤出控件，←→ 预览 ±10 秒，确认跳转 |
| 退出应用 | 首页连按两次返回键 |

## 构建

```bash
pnpm install
VITE_APP_EDITION=tv pnpm build     # 前端 + 老内核闸门
pnpm tauri android build --apk     # 出包（需要 Rust + Android SDK/NDK）
```

要核对前端是否真的进包：解开 APK 看 `lib/<abi>/libhghubx_lib.so` 的 md5，两次构建若一字不差说明 `rust-cache` 复用了旧产物（`src-tauri/build.rs` 已声明 `../dist` 依赖来防止这点）。

## 升级兼容

- 本地收藏、观看记录、偏好与主题使用 `hghubx_*` 存储键（与上游 TV 版一致，改名会丢用户数据）。旧 `hghub_*` 数据在首次启动时迁移到新键，已有新数据优先，写入成功后才清理旧键。
- 环境变量沿用 `HGHUBX_*` 前缀，旧 `HGHUB_*` 名称继续兼容；新变量未设置时才回退旧变量。
